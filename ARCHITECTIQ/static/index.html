The client challenge

A mid-sized enterprise wants an internal assistant to help employees find reliable answers across security, operations, and delivery policies. Leadership needs an architecture recommendation, a measurable quality baseline, and a clear understanding of operational risk.

Success criteria

Ground every answer in approved evidence. Abstain when evidence is missing. Demonstrate evaluation, traceability, access-control design, and cost awareness.

Reference architecture

A deliberately bounded architecture with explicit trust boundaries and a production gap register.

Request and evidence path

Employee→Identity + API gateway→Access policy gate*→Retriever→Evidence gate→Answer / abstain

*Identity and document permissions are architecture requirements, not implemented authentication in this local demo.

Implemented in this lab
