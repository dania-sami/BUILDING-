# HUMAN//SIGNAL — Talent Intelligence Studio

**Better hiring. Human at the core.**

An independent, interactive talent operations concept I built to explore how I could support a technical talent acquisition team with better role definition, structured interviews, thoughtful communication, and measurable process improvement. Inspired by the work of Knowit Connectivity and its talent acquisition teams; **not affiliated with or endorsed by Knowit**.

## Launch in one click

Extract the ZIP and double-click `index.html`. No terminal, server, Docker, accounts, or API keys. Internet is optional (only the Google Fonts import needs a connection).

## Seven functional workspaces

1. **Mission Control:** interactive overview of a fictional recruiting pipeline.
2. **Role Architect:** generate, copy, download, and save technical hiring briefs.
3. **Interview Studio:** generate structured interview questions and evidence rubrics for five technical focus areas.
4. **Talent Pipeline:** filter, add fictional profiles, manually update stages, remove profiles.
5. **Outreach Lab:** generate and export respectful candidate communications.
6. **Impact Analytics:** edit baseline and follow-up assumptions and export a CSV.
7. **Pilot Playbook:** practical 30-day rollout and a 45-minute workshop.

Changes are stored in your browser's local storage. Reset demo data in the sidebar. Export the fictional workspace as JSON.

## Project structure

- `index.html`: accessible entry point
- `assets/styles.css`: responsive design system
- `assets/data.js`: fictional sample dataset and navigation
- `assets/app.js`: interactions, rendering, state, exports
- `docs/PILOT_PLAYBOOK.md`: stakeholder pilot plan
- `docs/ETHICS_AND_LIMITATIONS.md`: guardrails and constraints
- `docs/WORKSHOP_AGENDA.md`: facilitator guide
- `examples/role-brief.md`: example role definition

## Responsible design

This is a **local browser simulation**, not an AI service or applicant tracking system. There is no model API, integration with Knowit, actual candidate information, or automated hiring decision. Every name and metric is fictional. Text generation uses deterministic templates. Human reviewers remain responsible for communications and decisions. The analytics demonstrate *how* a pilot could be evaluated, not actual measured improvements.

## Why I built this

Recruitment is a human experience supported by systems. I wanted to show an end-to-end approach: listen to the team, simplify role briefs, help hiring managers evaluate consistently, protect candidate communication, and track whether a pilot makes the experience better.
