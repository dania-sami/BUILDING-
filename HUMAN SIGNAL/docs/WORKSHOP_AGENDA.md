# 45-Minute Workshop: From Role Request to Evidence

**Audience:** recruiter, hiring manager, technical interviewer.

**0–5 min:** Define the actual hiring challenge and desired outcome.

**5–15 min:** Convert a vague technical role request into essential skills and trainable skills.

**15–30 min:** Co-create three consistent technical interview questions and a 1–4 evidence rubric.

**30–40 min:** Review candidate outreach for clarity, tone, accessibility and transparency.

**40–45 min:** Agree on a small pilot, owner, and metrics.

**Materials:** role brief, interview kit, communication template, pilot scorecard.

**Facilitator note:** avoid ranking candidates with automated scores or using personal data in unapproved systems.
