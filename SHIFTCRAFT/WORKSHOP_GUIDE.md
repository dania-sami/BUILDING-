# SHIFTCRAFT | 45-minute developer workshop

**Audience:** Development teams beginning a controlled AI coding assistant pilot.

**Outcome:** Participants can construct a context-rich prompt, critique an AI suggestion and explain the required review gates.

| Time | Segment | Facilitation |
| --- | --- | --- |
| 00–05 | Goal and guardrails | Ask what data is approved for prompts; identify one use case |
| 05–15 | Prompting with context | Compare vague and structured requests for the same task |
| 15–30 | Hands-on test design | Use `examples/dotnet/DiscountService.cs` and propose xUnit tests |
| 30–40 | Human review | Identify missing edge cases, ambiguous rules and unsupported assumptions |
| 40–45 | Pilot commitment | Agree on owner, quality metrics, feedback cadence and next check-in |

## Coaching questions

1. Which suggestions did the AI get wrong or leave unverified?
2. Which checks should CI enforce independently?
3. What information would be unsafe to include in a prompt?
4. What would count as meaningful improvement, beyond speed?

## Follow-up

Capture anonymous feedback, document reusable prompts, and plan a two-week pilot review.
