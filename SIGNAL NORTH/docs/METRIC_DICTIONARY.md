# Example KPI Dictionary

These are proposed definitions to validate with stakeholders, not Knowit definitions.

| Metric | Suggested calculation | Validation question |
|---|---|---|
| Lead volume | Count of deduplicated new leads in period | Are imported and recycled leads included? |
| MQL rate | MQL / lead count | What qualification rules apply? |
| SQL rate | SQL / MQL | What is the handoff acceptance rule? |
| Win rate | Won deals / SQL count | Are time periods cohort aligned? |
| Target attainment | Revenue / target | Currency, booking date and recognition policy? |
| Cost per lead | Channel spend / channel leads | Are costs complete and attributed consistently? |
| Cycle time | Days from qualified opportunity to closed-won | Are lost deals and outliers reported separately? |

## Governance fields for every KPI

Owner, system of record, SQL definition, refresh cadence, time zone, currency, privacy classification, access policy, and known caveats.
