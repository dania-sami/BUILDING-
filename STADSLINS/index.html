From fieldwork to evidence

01 · Instrument design

Structured Likert-scale survey, Swedish/English wording and response validation.

02 · Data quality

Python rejects invalid coordinates, ratings and categories; valid records are written to SQLite and CSV.

03 · Spatial methods

Haversine distance to area centroids; neighborhood-level aggregation. Spatial coordinates are fictional.

04 · Statistical analysis

R computes descriptive summaries, boxplots and a multivariable linear regression as a methodological illustration, not causal inference.

05 · Reproducible reporting

Python unit tests, an explicit data dictionary, transparent assumptions and machine-readable outputs.

Analysis toolkit

Python: csv, sqlite3, statistics, math, json, unittest.

R: aggregate, lm, boxplot and CSV outputs, all with base R.

GIS: point observations, area centroids, proximity calculations and geographic grouping.

Open data: documented import pathway for municipal geodata, OpenStreetMap and Swedish public data portals; no external datasets are claimed to be loaded.

SPSS/Excel: tabular CSV export for import. Native SPSS files are not generated.

This prototype intentionally avoids collecting real participant data or presenting simulated findings as evidence.
