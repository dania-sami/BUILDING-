# THREADLINE

I built THREADLINE to explore the part of requirements analysis I find most interesting: turning different people's needs into decisions a team can actually deliver.

It's a fictional municipal booking project with stakeholder conversations, conflicting priorities, acceptance criteria, traceability, impact analysis and a review report.

Run:

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Open http://127.0.0.1:8000

Everything is synthetic and runs locally.
